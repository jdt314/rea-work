# 复习模块实现与验证

日期：2026-10-21。承接用户的启动复习截图、视频 7 和 `cap.ipa` 研究。

## 已落地

- 启动提示按 602×1308 参考图调整五卡错层、关闭按钮、暖黄背景、文字层级、黑色开始按钮、彩色相机入口；问候与词数使用真实状态。
- 复习标签页提供今日状态、连续天数、可切月日历、所选日期统计和每日数量设置（5–40，步长 5）。
- 会话固定队列，支持翻面、左右滑动/按钮判断、三种文字模式、标准发音、完成统计和再练。
- 队列为全部到期词加限量新词；默认 5 个新词。正确后按 1、2、4 个日历日调度，再进入长期掌握；错误次日再练。
- 每词答题进度即时保存；整轮完成后写入当天的认识/未掌握记录。当天记录采用覆盖计数。
- 长期掌握标记独立保存，避免已掌握词在重练错误后重新进入普通到期队列。

## 实现选择与限制

原版“再次复习”的完整选词链、中途退出保存范围、日历缺口语义和语音评分尚未恢复。本地版明确采用本轮全队列再练、整轮完成才写日报、点击日期查看统计；这些是本地实现选择。用 `Date.distantFuture` 表示长期掌握后的无到期状态，同时保留独立掌握标记。

本轮没有实现麦克风识别和发音评分。现有发音按钮播放目标词，不产生识别分数。原版语音路径新增证据见 [语音补查](../../../capwords-analysis/review-page-20261020/speech-followup/REPORT.md)。

研究依据：[复习报告](../../../capwords-analysis/review-page-20261020/REPORT.md)、[数量设置补证](../../../capwords-analysis/review-page-20261020/completion-followup.md)、[启动提示补证](../../../capwords-analysis/review-page-20261020/startup-prompt/REPORT.md)。旧报告中的“当前工程实现差异”保留其历史时间点，以本文为当前实现说明。
