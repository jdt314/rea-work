## 拍摄和背景消散

[阶段联系表 1](dissolve/contact-000.jpg)、[阶段联系表 2](dissolve/contact-001.jpg)、[7.9 秒颗粒原图](dissolve/t0007900.jpg)。

| 实际时间近似 | 可见行为 |
| --- | --- |
| 4–7.7 秒 | 全屏相机，画面直达底部。底部左取消、中央彩色快门、右相册，没有白色纸张托盘。 |
| 7.800–7.867 秒 | 摄影背景先变为细密颗粒和局部模糊斑块，主体基本留在原位置。底部淡入左重做、中央白圆橙色勾、右裁剪。 |
| 7.867–8.400 秒 | 背景以不均匀速度消散，照片纹理局部化为细碎噪声，底层灰褐色逐渐露出；右侧桌面残留略久。 |
| 8.500 秒 | 背景基本成为均匀灰褐色；扩展坞、连接线和 USB 端头保留。可见颗粒阶段约 0.7 秒。 |
| 8.5–10.3 秒 | 主体保持接近照片中的大尺寸。背景、主体、底部操作稳定停留。右上「识别整张图片」提示仍在。 |
| 10.400 秒 | 底部开始出现向上展开的白色圆角页面，同时旧背景短暂变黑、主体变暗并开始缩小。 |
| 10.500–10.700 秒 | 白页快速向上展开；贴纸移动并缩小，软阴影可见。 |
| 10.800–11.000 秒 | 白色点阵页铺满，贴纸白边出现；取消胶囊在底部。 |

颗粒细节与方向的可确认程度：

- 主体独立保留，颗粒基本属于背景；不能把整张照片作为均匀爆炸效果。
- 在 592 px 宽的视频里颗粒非常细，更多呈现为密集噪声和局部纹理的退散；没有明显的大方块飞溅。
- 各位置的起始/消失时间不同，不能拟合成一道整齐的水平或竖直擦除边界。
- 此视频的分辨率与压缩不足以稳定追踪单个粒子，**无法可靠恢复具体速度、角度、加速度或全局方向**。目视没有明显整体向下坠落，也没有支持统一的中心径向爆炸；应以 IPA shader 证据确定物理参数。
- 消散后的均匀背景是灰褐色，观察上与当次照片主色协调；单个样本不足以证明它由平均色计算。
- 8.5–10.3 秒有三项明确操作，不应把整段时长直接写成固定 sleep。视频没有触摸标记；「用户确认前景后再识别」是合理交互解释，仍须 IPA/运行时证据确认。

## 白底等待与结果氛围

[12 秒等待原图](overview/t0012000.jpg)、[17 秒过渡原图](overview/t0017000.jpg)、[18 秒结果原图](overview/t0018000.jpg)、[结果联系表](result/contact-000.jpg)。

- 11.0–16.9 秒等待持续约 6 秒，主体在白底上上下浮动，白色轮廓与软投影保留。该时长可能包含识别等待，不应成为固定动画常量。
- 全页有浅灰色规则点阵，间距约 29 px（4.9% W）。主体周围的部分网格点变为彩色、增大或缩小，形成环状包络；中心稀小，外缘渐隐。
- 彩点直径约 2–7 px，网格位置保持规则；效果来自点大小/不透明度的循环变化，不是粒子从主体飞走，也不是椭圆涟漪。
- 大致颜色分布为左上黄、右上绿、左下青、右下紫；包络中心约 x 296、y 550，外半径约 235 px。不能仅从抽帧确认整个色场是否旋转。
- 16.933 秒贴纸开始向上移动；17.000–17.100 秒黄色柔光与白色小星芒叠入，彩点短暂保留。主体从等待时的 y≈560 移到结果时的 y≈420，并稍缩小。
- 17.233 秒名称/译文开始出现；17.533 秒三操作基本完整。黄色柔光、星芒与主体轻微动态继续。
- 结果操作为左重做、中央保存勾、右关闭。原图中中心按钮约 118 px，左右约 88 px；勾和朗读声波为橙色。下方为可编辑名称提示胶囊。
- 约 20.0 秒保存开始，结果贴纸与列表并存，随后缩小回到列表左上位置；这部分仅用于确认与列表淡入重叠。

## 与本次修改前 Swift 实现的差异

以下描述对照 2026-10-18 开始任务时的源码；后续实现可能已经修改。

| 原实现 | 视频证据要求 |
| --- | --- |
| LibraryView 底栏是日期、快门、分类三项 | 主页四项玻璃胶囊；日期/分类属于右上菜单；按日期分组的展开词卡列表是单快门 |
| cameraControls 带白色圆角纸张托盘 | 此录屏的相机取景全屏到底，操作悬浮 |
| DustSampler 宽 108 网格；PhotoDustView 随机 360° 散射且 `+60*t*t` 下落 | 视频颗粒更细，底图逐片退散；下落加速度无法由视频确认 |
| 0.75 秒后直接 floating，0.7 秒后自动 result | 灰褐前景确认与白页等待是不同阶段；等待长短依识别结果变化 |
| floating 时背景立刻换为 PaperBackground | 白页自底展开，与主体缩小重叠 |
| SubjectEnergyView 是轮廓 AngularGradient 和三个扩散椭圆 | 白底等待是规则彩色点阵的大小/透明度波动 |
| 主体固定额外旋转 -4°，没有实际周期浮动 | 等待有可见浮动；原照片主体角度应保留，不能凭视频添加固定转角 |
| 结果保存勾、朗读按钮偏紫/黑色 | 两者橙色；结果后层黄色柔光并带白色小星芒 |

视频未覆盖点击「对话」「复习」「个人」后的页面，不能据此构造它们的详细交互或内容。
