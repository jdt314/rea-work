# 闪卡反面与叠卡调整

参考：用户提供的白色反面截图（reference.png）及视频7正面。

- 第二层由3°调整到-7°，第三层由10°调整到11°，让第二层向相反方向展开。
- 原先翻面只在彩色卡片里替换释义；现在使用独立白色纸纹反面，音标和发音按钮在上、英文词居左、横线分区、大号中文在下、左下保留浅灰标记。
- 正反面有三维翻转和隐藏面的触控/可访问性隔离，开启减少动态效果时直接切换；背面隐藏后层卡片，采用参考图约1.59高宽比。
- 点卡翻面不修改复习次数；滑动换卡后回到正面。增加VoiceOver翻面操作。回归测试加入反面释义可见、进度不变、再次点击回正面的断言。
- 语音仅规划，未接入录音；方案见 ../review-speech-input-plan.md。

构建和截图结果见 VERIFICATION.md；启动参数直达反面只用于 DEBUG 且需 --uitesting，不代表实际点击测试已通过。
