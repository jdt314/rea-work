# 视频 4 实现验收

本目录是本项目在 iPhone 17 Pro / iOS 26.1 模拟器的真实渲染。识别使用 Debug 演示数据，快返回、8 秒延迟、网络错误和取消由参数模拟；不代表 DeepSeek 的实际速度或质量。

- `slow.mp4`：拍摄准备、消散、确认、白页展开、悬浮等待和结果揭示。
- `slow-13.0.png`、`fast-6.0.png`：慢/快返回的最终结果。
- `failure-6.0.png`：失败仍保留主体，提供重试、手动填写与取消。
- `cancel-14.0.png`：取消并超过原请求演示延迟后仍留在相机，没有旧结果重新出现。
- `final-transition/`：最终录像 3.0–6.5 秒的过渡采样与实际 PTS；人工检查采样帧未再见双主体交叉淡化。`frames/` 为较早一轮采样，最终验收以 `final-transition/` 为准。
- `core-tests.log`：39 项核心测试通过。
- `build.log`：模拟器构建成功；AppIntents 元数据提示不影响构建。

截图文件名是计划采样时间，真实截图结束时间见 `metadata.json`，不能拿文件名作毫秒级动画测量。启动、截图与系统状态栏会受模拟器环境影响。首轮发现的主体重影已通过图片内容禁用隐式交叉淡化及展开后再悬浮处理；最终采样人工检查情况见研究报告。

复现命令见 [拍照识别流程报告](../2026-10-19_逆向-CapWords拍照识别流程-report.md)。截图验证不是 XCTest 触摸自动化；本轮没有使用真实相机、真实 API 或自动点击保存。
