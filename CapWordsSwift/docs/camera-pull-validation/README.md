# 今日顶部下拉进入相机

2026-10-19：空白今日和已有词卡的今日使用同一套下拉相机转场。白色词库整页跟手下移，顶部连续圆角增大；达到距离或速度条件后补完，短拖回弹。关闭相机时先隐藏取景，再让白页返回原位。

## 依据与范围

- 用户要求两种今日状态都支持下拉相机；历史列表中途开始的滑动不打开相机。
- [视频 3 逐帧研究](../video-3-evidence/notes.md)确认满宽下移、日期略上移变白、数量消失、快门固定并放大约 1.19 倍。纸面快速退场约 0.4 秒，关闭含收尾约 0.5 秒。录屏不含手指轨迹，不能确定原版阈值或松手时刻。
- [最新版 IPA 的 REA 研究](../video-3-evidence/ipa-camera-notes.md)确认 2.0.11 / build 23、本地化下滑提示及触觉资源。主程序 FairPlay 加密，未恢复原版手势方法、阈值、弹簧或相机预热代码。`Inflate.ahap` 的页面绑定未知，未将其时间当作相机转场时长。

## 实现

| 项目 | 当前行为 |
| --- | --- |
| 入口 | 日期模式、今天顶部开始的向下纵向拖动；空白今日及有词今日共用判断 |
| 跟手 | 使用屏幕坐标测量，位移对应整张纸面下移；避免移动容器改变手势坐标 |
| 提交 | 距离达到 `min(110 pt, 屏高 × 0.14)`；或实际拖动至少 32 pt 且预测距离达到阈值的 1.7 倍 |
| 取消 | 短拖或取消手势回弹；等待正常 `onEnded` 后再处理手势取消兜底 |
| 纸面 | 保持满宽，最大顶角约 48 pt，不对整个词库施加缩放；关闭恢复原列表位置 |
| 日期 | 固定在上方，进入相机时上移 18 pt、变白、数量渐隐 |
| 快门 | 保持中心位置，最大放大 19%，内圈扩大；转场期间在纸面上方显示 |
| 相机控件 | 左右按钮随展开出现；纸面退场后四角和提示以 0.2 秒淡入；关闭先隐藏预览及左右控件 |
| 弹簧 | 打开 response 0.42 / damping 0.90；关闭 response 0.42 / damping 0.88；减少动态效果时取消这些弹簧 |
| 触感 | 提交下拉时一次 soft impact；空白今日与历史之间原有整页切换触感保留 |
| 原有流程 | 空白今日上滑进入历史、历史整页返回空白今日；有词日期正常连续滚动；拍摄、相册、识别和保存继续使用既有流程 |

阈值、圆角、控件显隐和弹簧均为根据视频重建的参数，不是从最新版 IPA 中恢复的常量。相机实际预览按设备准备状态显示，没有为了模拟原录像的相机启动延迟而硬编码黑屏等待。

## 渲染检查

使用 iPhone 17 Pro / iOS 26.1 模拟器，1206 × 2622 像素。`--uitesting` 使用内存数据；Debug 的 `--preview-camera-motion` 程序化设置部分展开状态，再调用实际打开和关闭方法。

**这些录屏验证渲染与状态恢复，不是实际触摸手势测试，也不证明拖动仲裁或真机震感已验收。** 为便于截图，采样特意停留在部分展开和完整相机状态，录屏总时长不能当作用户一次手势的耗时。

已核对纸面退场后无底部白边、快门中心不跳动、日期颜色与位置切换，以及两种场景关闭后原日内容恢复。模拟器使用带示例标识的参考图，图中已有的局部四角属于图像本身；它与新绘制的大取景框不是同一层。系统状态栏仍沿用应用现有的浅色模式，与原录像相机态的浅色状态栏不同。

有词场景另有 [0.1 秒间隔抽帧](populated/frames/metadata.json)。模拟器录像为可变帧率，静止时会重复返回最近一帧；必须使用元数据中的 `actualSeconds`，不能把请求时间或重复帧当作新的观测。

## 测试结果与待验收项

- 核心测试：30 项通过，含相机入口范围、拖动方向、距离映射、短拖取消、长拖和预测距离提交。
- App、单元测试及 UI 测试 target：`build-for-testing` 通过。
- UI 用例已覆盖空白今日下拉、有词今日下拉、关闭回原日、短拖回弹，以及之前的空白页双向切换和普通滚动。
- 当前机器的 XCTest runner 持续报 `DTServiceHubClient failed to bless service hub`，因此上述 UI 用例尚未执行。真实触摸手势与 ScrollView 的仲裁、相机权限弹窗期间取消、实际拍摄保存回归和 iPhone 触觉强度仍需设备验证。

## 复现

在仓库根目录运行，模拟器须已启动并安装最新 Debug App：

```sh
export CAPWORDS_SIMULATOR_ID=4607AA88-3821-4245-91AA-A1E6B8E407E4
python3 CapWordsSwift/scripts/capture_camera_pull.py empty
python3 CapWordsSwift/scripts/capture_camera_pull.py populated
```

脚本会覆盖本目录对应场景的检查画面和录屏，并将开发 App 留在该场景的今日列表。核心测试和构建命令见[项目 README](../../README.md)。
