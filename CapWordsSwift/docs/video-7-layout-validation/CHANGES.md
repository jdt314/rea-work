# 视频 7 页面细节调整

依据：`7.mp4` 的 1 秒闪卡、18 秒文字菜单和 22 秒复习月历，原始帧见 `capwords-analysis/review-page-20261020/video/`。

- 闪卡页改为浅灰背景；卡面宽约屏宽 64%，高宽比 1.39；后方两张卡采用 3°/10°错角。
- 卡面使用灰褐、浅灰绿、土褐色和颗粒纹理，缩小叠卡阴影；白色粗体词语、音标及紧邻的播放按钮取代原先黑色文字和卡外播放行。
- 顶部计数区分黑色当前数量和灰色总量，右侧为省略号；三种文字菜单添加对应图标。
- 移除视频中没有的底部两枚判定按钮和操作说明；左右滑动与 VoiceOver 自定义判定操作保留。
- 正常动画先滑出卡片，再更新计数；动画期间阻止重复判定，减少动态效果开启时直接推进。
- 底部对齐灰色提示、虚线圆形麦克风及星形装饰。点击显示尚未接入语音识别的说明，不模拟录音或评分；卡内播放按钮仍可朗读。
- 复习首页标题居中，开始按钮改为较窄的黑色胶囊；每日数量按钮改为浅灰胶囊。
- 月历采用白色圆角面板、日期标题、浅灰圆形翻月按钮、分隔线、橙色星期标题；日期数字置于圆点下方，星期以周日开头。真实记录用橙色填充，选中日期描边，不虚构视频中 18 日的记录或缺口语义。

调度、队列和日报规则不变。截图使用实际测试词库，因此单词与视频、数量与视频中的 11 均可能不同。

UI 回归脚本同步改用左右滑动。验证结果和截图见同目录 `VERIFICATION.md`；构建通过不代表交互测试通过。
