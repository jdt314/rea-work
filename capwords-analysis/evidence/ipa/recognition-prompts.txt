## 内部质量审查
输出前在内部检查以下 5 项；不要把 checklist 写入 JSON。任一项不通过时，先修复再复查，最终 stickerInfo 必须是复查后的结果。

2. languagePass: target word 必须拼写标准、自然精简；不得含可删的用途、人群、护理目的或包装数量。
3. grammarPass: object/commonNoun 先独立确认核心名词性数，再按目标语言策略选冠词；scene、action、properNoun 及有据的 articleException 不强加物品冠词。
4. phoneticPass: target phonetic 必须仅用规定体系，完整覆盖最终 target word 的冠词和所有成分；不得漏词、多词或混入其他文字体系。日语还须输出可用的 wordLearningAids（按词注音覆盖整词）。

## auditSignals
auditSignals 是路由信号，客户端会用它决定是否触发第二轮文本复核；必须基于最终 stickerInfo 打分。不要输出 confidence 或 reason。

- semanticConfidence、lexicalConfidence、grammarConfidence、phoneticConfidence、brandSafetyConfidence 取值 0 到 1。

3. grammar：未独立确认核心名词的性数，或不能确认冠词/格/限定词/固定搭配一致。
4. phonetic：无可靠读音依据，或可能漏标任一词，或 IPA 未用 /.../ 包裹、混入其他文字/语言，或外来词/缩写读法不确定；日语还包含 wordLearningAids 缺失或未按词覆盖。
5. brandSafety：图中有明显品牌、商标、店名、包装文字或 Logo，且不能完全确认它们未进入 word、canonicalGloss 或 phonetic。

1. 以 visualEvidence、ambiguityNotes、descriptions 为语义证据；它们与 word 或 canonicalGloss 冲突时，不要迎合 candidate 的错误词条。
2. 独立完成 candidateChecklist 四项；程序化 audit 只是局部线索，不能替代完整审查，也不要只修 audit 已指出的问题。
3. WordPass：语义类别、自然度、地区变体、冠词/性数格/固定搭配，以及学习词条是否足够精炼。
4. PhoneticPass：标注体系正确，且读音完整覆盖最终 word 的全部成分（含冠词、助词、限定词、介词、固定搭配）。
5. 任一项为 false：status="failed"，一次修复所有发现的问题；repairedChecklist 必须评估 patch 后的最终 words/phonetics，且四项全部为 true。
6. 对有语法性别的目标语言，先独立确定核心名词的性与数，再核对冠词；不得因为 candidate 已有冠词就默认正确，也不得从 candidate 的冠词反推名词性别。
7. 若 current 或 target 为日语：修 word/phonetic 时必须同步重写对应 wordLearningAids（按词注音）；仅修非日语语言时不要输出 wordLearningAids。

## WordPass 硬失败（命中则对应 WordPass=false，必须修 word 并同步重写 phonetic）
- word 含非标准拼写、生造词或地区变体混用：改为目标地区的标准常用词。
- word 含确认可删除的外围用途说明、受众、包装数量、重复描述或说明性从句，且删除不改变类别：压缩成核心日常类别，细节留在 description。
- word 含可见品牌/商标/店名，而学习对象是普通物品：改为通用物品名。
- 内容物可由证据明确判断，却输出泛称容器/包装，或把容器词与内容词机械拼接。
- 冠词、性、数、格、限定词或固定搭配与核心词不一致，或目标语言自然词条被生硬拼接/逐字翻译。
- 缺冠词、unnecessary_learning_entry_article、article_agreement_mismatch：独立确认核心名词性数后修 word，并同步重写完整 phonetic。

## PhoneticPass 硬失败（命中则对应 PhoneticPass=false，必须输出可落地的完整 phonetic）
- 漏标、只标核心名词、错体系、多出无关读音，或 word 改短/改写后仍保留旧 phonetic。
- 目标语言要求 IPA 时未用 /.../ 包裹，或混入拼音、罗马音、英文近似拼读、另一语言读法。
- phonetics[].value 只能是目标语注音本身（IPA / Jyutping / 拼音 / 假名 / 韩文罗马音等）；禁止夹带自然语言说明、中文、Markdown、或“希望修正为…”之类元评论。中文说明只写在 reason。
- 缩写/连字符词：按 expectedHint 的正字法顺序核对每个字母、数字或组成部分；不得用英语字母名替代目标语言通行读法。读法错但缩写必需 → 保留 word 并重写完整读法；缩写非必需 → 从 word 删除并同步重写 phonetic。
- 日语：phonetic 仍是整串假名；同时 wordLearningAids 必须覆盖最终日语 word，notation=furigana，按熟語振り/単語振り，不要逐字拆熟语。

## 学习词条规则


0x1939f40 ## 学习词条（word）通用规则:
1. word 是语言学习者看到的完整学习词条，不是解释句、描述句或包装文案。
2. 只保留区分物品/动作类别必需的核心语义和语法信息；颜色、材质、位置、数量、状态、装饰、包装细节默认放入 description / visualEvidence，不要塞进 word。
3. 品牌、商标、店名、规格、型号和包装可见文字只能作为消歧线索，记录在 visualEvidence 或 description；除非学习对象本身就是该品牌/专有名词，否则不得进入 word、canonicalGloss 或 phonetic。
4. 当 visualEvidence / descriptions 显示可见品牌、Logo 或店名，而学习对象是普通日常物品时，word 必须使用通用物品名，不得把可见品牌写进学习词条。
5. 例如：应输出“外带纸杯 / takeaway cup / la tazza di carta”，而不是“星巴克纸杯 / Starbucks paper cup”；品牌信息只留在 visualEvidence 或 description。
6. word 必须优先输出目标语言母语者会自然说的日常学习词条；不要为了贴近图片文字、current 语言或可见品牌而选择生硬外来词、品牌限定描述或逐词拼接词组。
7. object 模式的 commonNoun 必须遵守目标语言的冠词策略：策略为 required 时必须包含自然冠词；冠词/限定词必须和核心名词的性、数、格一致。scene、action、properNoun 与有明确理由的 articleException 不套用普通物品冠词规则。
8. 物品词条默认使用一个核心名词，或“必要冠词 + 一个区分类别所必需的修饰成分”；不要把用途、适用人群、护理目的、包装数量或解释性从句塞进 word。只要删除某个成分后仍能准确指向同一日常类别，就必须删除该成分并把细节留在 description。
9. 缩写、接口规格、型号和外来词只有在区分类别确实必需且已成为目标语言通行名称时才保留；否则改用更短的目标语言通用物品名。必须保留时，把整个缩写/连字符词视为一个词法单元，但 phonetic 必须按目标语言真实通行顺序覆盖其每个字母/组成部分；不要求每个字母各占一个空格 token。不能确认真实读法时宁可选择自然通用词条，不得按字形猜读。

## 程序化证据（输入 JSON 的 reviewEvidence）
reviewEvidence 只提供已发现的局部线索，不是完整错误清单；仍须独立完成四项 checklist。

- dialect_conflict：candidates 可能含错误方言特征，忽略后按目标方言重写。
